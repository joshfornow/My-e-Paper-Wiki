# HINK-E0276A01

![Panel](pictures/SL-28-BK-280-BWRY-black-screen-01.png)

Four-color panel (black, white, red, yellow), about **2.8"** (flex `0276` ≈ 2.76"). From Solum 2.8 BK.

## Notes

|                 |                                         |
| --------------- | --------------------------------------- |
| Flex            | HINK-E0276A01-A0, DEN 2604              |
| Other mark      | VE0276A01                               |
| Resolution      | 296×128 after rotation (native 128×296) |
| Active area     | about 64 × 30 mm                        |
| Controller      | SSD2680ZA                               |
| BUSY            | idle HIGH, active LOW                   |

## Code

Custom class `GxEPD2_276c_E0276A01`. `setRotation(1)` → 296×128.
